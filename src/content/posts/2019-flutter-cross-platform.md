2018 年 12 月，Google 在 Flutter Live 上宣布 Flutter 1.0 正式发布。但在社区层面，Flutter 真正的起飞年是在 2019 年。

## 对 React Native 的挑战

React Native 发布以来一直是跨平台移动开发的首选方案。但 Flutter 带来了几个不同的技术选择：

- 自绘引擎（Skia）而非原生控件桥接——性能更可预测
- Dart 语言而非 JavaScript——编译为原生 ARM 代码
- 同时覆盖 iOS 和 Android，且 UI 一致性更高

2019 年 Stack Overflow 开发者调查中，Flutter 被评为"最受喜爱的框架"之一，高达 75.4% 的受访者表示愿意继续使用——这个数据在当时极为亮眼。

## 关键里程碑

2019 年 Flutter 经历了快速迭代：

- 2019 年 2 月：Flutter 1.2 发布，改进了开发者工具链
- 2019 年 5 月：Google I/O 宣布 Flutter for Web 技术预览版——从"移动端框架"到"全平台 UI 框架"
- 2019 年 9 月：Flutter 1.9 发布，macOS Catalina 兼容，Material Design 组件更新
- 2019 年底：大量生产应用开始采用 Flutter，包括阿里巴巴、腾讯等中国互联网公司的多个产品线

## Dart 语言的复兴

Flutter 的成功意外复活了 Dart 语言。原本在 TypeScript 面前失去吸引力的 Dart，因为 Flutter 而获得了明确的生存空间。Google 也宣布 Flutter 和 Dart 是中长期投入方向。

**观点判断：** Flutter 在 2019 年的快速增长反映了一个行业规律：跨平台方案的成功不只取决于技术本身，还取决于生态、团队投入和时机。Flutter 恰好赶上了移动端应用对性能和 UI 一致性要求提升的周期，而 React Native 社区当时也处于重构和调整期。

## 小结

2019 年是 Flutter 从"Google 的新潮框架"走向"跨平台开发严肃选项"的一年。Web 支持的技术预览版更是将 Flutter 的能力边界从移动端扩展到了全平台。对于开发者来说，它代表着跨平台方案在"接近原生体验"这个方向上迈出的重要一步。
