2017 年，Google 宣布 TensorFlow 1.0。这个版本把 Python API 稳定性作为重点之一，也继续扩展 Java、Go 等语言的实验接口。

这类发布意味着机器学习框架开始更明确地面对工程落地：不只是研究模型能跑起来，还要考虑版本稳定、生产部署和团队协作。
